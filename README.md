# Nucleomics-VIB / .github

This repository holds the **VIB Nucleomics Core** organization profile page, rendered
at <https://github.com/Nucleomics-VIB>.

- [`profile/README.md`](profile/README.md) — the organization landing page
- [`profile/families/`](profile/families/) — per-family repository indexes

It also holds the **default community health files** for the organization. GitHub applies
these to every public Nucleomics-VIB repository that does not carry its own copy:

- [`CONTRIBUTING.md`](CONTRIBUTING.md) — how to report a problem and propose a change
- [`SECURITY.md`](SECURITY.md) — how to report something that should not be public
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) — bug, change, and "which tool do I need?" forms
- [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) — the PR checklist

A repository that defines its own version of any of these overrides the default.

Looking for our code? Start at the [organization page](https://github.com/Nucleomics-VIB).
